## Polski

### Czym jest program

**Planer Okablowania** (*LAN-Planer*) to prosta aplikacja w przeglądarce do planowania sieci komputerowej (LAN) na planie pomieszczenia. Na rysunku stawiasz gniazda, szafę rack, switch, router, access pointy i inne urządzenia, a potem prowadzisz trasy kabli i od razu widzisz długości oraz zestawienie materiałów.

Nie wymaga instalacji ani konta — wystarczy otworzyć plik HTML.

Program jest całkowicie darmowy i **nie wymaga żadnej licencji** ani aktywacji.

### Cel

- zaplanować, gdzie staną gniazda i sprzęt sieciowy,
- narysować trasy kabli (także wiązki wielu przewodów),
- policzyć metraż i orientacyjną liczbę szpul kabla miedzianego (Cat),
- przygotować podgląd planu i listę materiałów (eksport JPG).

### Jak uruchomić

1. Pobierz **LAN-Planer-2.html** z [Releases](https://github.com/godlewskigm-gm/LAN-Planer/releases/latest).
2. Dwukrotnie kliknij plik albo przeciągnij go do przeglądarki (Chrome / Edge).
3. Języki: **PL / EN / DE / UA / RU** oraz wybór motywu kolorystycznego.

Praca odbywa się lokalnie. Projekty możesz zapisać w przeglądarce albo wyeksportować do pliku.

### Jak zacząć — krótki przepis

1. **Wczytaj plan** (zdjęcie JPG/PNG/SVG albo JSON ze skanu).
2. Jeśli to zdjęcie — **Kalibruj skalę** (odcinek o znanej długości w metrach).
3. Z lewego paska stawaj gniazda i urządzenia.
4. Narzędziem **kabel** poprowadź trasy; sprawdź zakładkę **Materiały**.
5. **Zapisz** w przeglądarce, **JSON** albo **Eksport JPG**.

### Czego program nie robi

To narzędzie do szybkiego planowania i szacowania materiałów — **nie zastępuje** pełnej dokumentacji wykonawczej ani programu CAD.

## English

### What the program is

**Cable Planner** (*Planer Okablowania* / *LAN-Planer*) is a simple browser app for planning a computer network (LAN) on a room plan. You place outlets, a rack, switch, router, access points and other devices, draw cable routes, and immediately see lengths and a materials list.

No install and no account — open the HTML file and start.

The software is completely free and **does not require any license** or activation.

### Purpose

- plan where outlets and network gear go,
- draw cable routes (including multi-cable bundles),
- estimate copper Cat cable length and spool counts,
- export a plan preview and materials list (JPG).

### How to run it

1. Download **LAN-Planer-2.html** from [Releases](https://github.com/godlewskigm-gm/LAN-Planer/releases/latest).
2. Double-click it or drag it into a browser (Chrome / Edge).
3. Languages: **PL / EN / DE / UA / RU**, plus theme selection.

Work stays local. Save projects in the browser or export to a file.

### How to start — short recipe

1. **Load plan** (JPG/PNG/SVG photo or scan JSON).
2. For photos — **Calibrate scale** (a known length in metres).
3. Place outlets and devices from the left toolbar.
4. Draw **cables**; check the **Materials** tab.
5. **Save** in the browser, export **JSON**, or **Export JPG**.

### What the program does not do

It is for quick planning and material estimates — it **does not replace** full as-built documentation or CAD for formal electrical/network designs.
